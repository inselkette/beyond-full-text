# Beyond Full Text

**AI-Assisted Discovery of Public Sector Documents**

University capstone project exploring whether large language models can help libraries make the informational content of archived public-sector documents accessible through copyright-conscious summaries, without republishing the original full texts.

The project will investigate summarization quality, copyright considerations, source transparency, and human review. A Python-based processing pipeline and a standalone web interface are planned.

**Current stage:** One-page project proposal.

Read the [one-page proposal](proposal.md).

*This is an academic prototype. Public availability of a document does not necessarily imply permission to reuse or process it.*
